4. HTTPS Deep Link (App Links/Universal Links)

Mở qua HTTPS domain (cần cấu hình App Links/Universal Links)

Mở qua HTTPS
https://lehuuthanh23.github.io/demo-deep-link/product/99

📱 Hướng dẫn sử dụng

  • Android: Tap vào link → Chọn app để mở
  • iOS: Long press link → Chọn "Open in [App Name]"
  • Custom Scheme (demoapp://): Hoạt động ngay lập tức
  • HTTPS Links: Cần cấu hình App Links (Android) và Universal Links (iOS)

🔧 Tình trạng cấu hình

  • ✅ Custom URL Scheme (demoapp://): Đã cấu hình
  • ⚠️ Android App Links: Cần thêm SHA-256 fingerprint
  • ⚠️ iOS Universal Links: Cần thêm Apple Team ID
